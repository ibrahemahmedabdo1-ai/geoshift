# GeoShift

1. ارفع محتوى المجلد ده على ريبو GitHub جديد (فرع main).
2. من تبويب Actions شغّل "Build APK" وبعد ما يخلص نزّل GeoShift-apk.
3. ثبّت الـ APK، وفعّل خيارات المطور من الهاتف.
4. خيارات المطور ← Select mock location app ← GeoShift.
5. افتح التطبيق، اختار المكان من الخريطة أو البحث أو المفضلة، واضغط "ابدأ الموقع الوهمي".
6. الجويستيك بيحرّك الموقع بسرعة المشي/العجلة/العربية اللي تختارها.
